# Movement Permit Format & Vehicle Biosecurity Standards

## Part A — Official Movement Permit

### Mandate
Under IGAD LITS Art. 27–31, every livestock movement across premises, regions, or borders requires an official movement permit issued by an authorised government veterinary officer.

### Permit Number Format
```
PRM-{REGION_CODE}-{YEAR}-{SEQ}
e.g. PRM-MOG-2026-00342
```
- Region code: 3-letter ISO-style region code
- Year: 4-digit
- Seq: sequential 5-digit number from DB function `generate_permit_number(p_region)`

### Permit Validity by Movement Type
**Source:** IGAD LITS Art. 29; Kenya KAMIS movement type schedule; Ethiopia NLIMS validity table

| Code | Movement Type | Validity (days) | Rationale |
|---|---|---|---|
| P2P | Premises-to-Premises | 5 | Short local movement |
| F2M | Farm to Market | 2 | Market day + return window |
| M2P | Market to Premises | 3 | Post-market transit |
| F2Q | Farm to Quarantine Station | 3 | Pre-export entry |
| Q2S | Quarantine to Slaughter | 1 | Same-day or next-day slaughter |
| Q2E | Quarantine to Export | 2 | Loading + crossing window |
| TRH | Transhumance (Seasonal) | 60 | Pastoral routes across regions |
| EMG | Emergency Movement | 1 | Disease emergency evacuation |

### Required Permit Fields (IGAD LITS Art. 30)

**Document identity:**
- Permit number (unique, sequential)
- Issue date
- Valid from — valid to
- Movement type

**Owner details:**
- Full name
- National ID (where available)

**Origin premises:**
- Premises code
- Premises name
- Region / administrative division
- GPS coordinates (where available)

**Destination premises:**
- Premises code
- Premises name
- Region / administrative division

**Livestock details:**
- Species
- Total count
- Sex breakdown (M / F / Castrated)
- RFID tag / ear tag serials for all animals

**Transport details:**
- Vehicle registration number
- Transporter name / company

**Inspection linkage:**
- Inspection code
- Inspector name and role
- Inspection date
- Overall inspection decision (PASS / CONDITIONAL PASS / FAIL)

**Special conditions:**
- Free text field for any movement restrictions or requirements

**Official certification:**
- Issuing officer full name
- Issuing officer veterinary licence number (`issued_by_licence`)
- Issue date
- Signature and official stamp space

**Legal warning:** Permit is void if altered; must accompany animals at all times; false declaration is a criminal offence.

### Implementation: Two Permit Issuance Flows

**Flow 1 — Field Inspector (auto-issue on PASS):**  
`InspectionWorkflowPage.tsx` → `handleSubmit()` → when `mvStatus === 'PERMIT_ISSUED'` → creates permit with:
- Validity from `typeValidityDays[movementTypeCode]`
- `permit_type = movementTypeCode`
- `species_summary` from `inspection.speciesSummary`
- `issued_by_name` from `inspection.assignedToName`

**Flow 2 — Ministry Officer (manual issuance):**  
`MovementsPage.tsx` → `doIssuePermit()` → creates permit with:
- Validity pre-calculated in `openPermitDialog` using `typeValidityDays[movementTypeCode]`
- `permit_type = permitTarget.movementTypeCode`
- `species_summary = permitTarget.animal`

## Part B — Vehicle Biosecurity Inspection

### Mandate
WOAH Terrestrial Code Chapter 5.3 — All vehicles used for livestock transport must be inspected before loading.

### Inspection Fields

| Field | Type | Options / Format |
|---|---|---|
| vehicleType | enum | Truck / Lorry / Pickup / Trailer / Railway / Other |
| cleanliness | enum | Clean / Needs cleaning / Rejected |
| previousLoad | text | Previous cargo type (livestock species, feed, other) |
| disinfectionApplied | boolean | Yes / No |
| disinfectant | text | Product name (if applied) |
| ventilationAdequate | enum | Adequate / Marginal / Inadequate |
| loadingDensityOk | enum | Adequate / Overcrowded / Under-capacity |
| waterProvided | boolean | Yes / No (required for journeys > 8 hrs) |
| feedProvided | boolean | Yes / No (required for journeys > 12 hrs) |
| journeyHours | number | Estimated journey duration |
| notes | text | Free text observations |

### Rejection Criteria
- Cleanliness = "Rejected" → vehicle must be cleaned and re-inspected before loading
- Ventilation = "Inadequate" → movement suspended
- Previous load of a disease-risk species without disinfection → movement suspended

### Database Storage
`movement_inspections.vehicle_inspection JSONB`

```json
{
  "vehicleType": "Truck",
  "cleanliness": "Clean",
  "previousLoad": "Cattle",
  "disinfectionApplied": true,
  "disinfectant": "Virocid 0.5%",
  "ventilationAdequate": "Adequate",
  "loadingDensityOk": "Adequate",
  "waterProvided": true,
  "feedProvided": false,
  "journeyHours": "6",
  "notes": ""
}
```

### Workflow Position
Vehicle inspection is the **3rd step** (VEHICLE) in the inspection workflow:  
`OVERVIEW → ARRIVAL → VEHICLE → ANIMALS → DECISION → SUBMIT`

Vehicle data is saved to `movement_inspections` via `handleSaveVehicle()` before proceeding to animal inspections.
