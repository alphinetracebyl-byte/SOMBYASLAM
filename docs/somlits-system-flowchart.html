Module 04 Field Checkpoint — RFID Scan & Identity Verification
Field Officer Field Portal :3002
10
RFID Tag Scan at Road Checkpoint
Field officer scans ear tag — system performs real-time multi-table lookup
Field OfficerField Portal :3002
Officer types or scans the RFID / ear tag serial. System performs a sequential Supabase lookup:
  • Step 1 — Animal lookup: animals by ilike('tag_serial', input) — returns animal identity, species, breed, sex, age, weight, status
  • Step 2 — Premises + Permit (parallel): farmer_premises by current_premises_id AND farmer_movement_requests filtered to active statuses (APPROVED / PERMIT_ISSUED / IN_TRANSIT / DEPARTURE_CONFIRMED)
  • Step 3 — Owner name: farmers by farmer_id from premises record
  • Health flags: built from animals.status — any of RESTRICTED / QUARANTINED / SICK / DEAD / SUSPENDED triggers a flag
Result displayed: animal identity · owner name · origin premises · active movement permit · health flags
Business rules
  • Tag lookup is case-insensitive (ilike) to handle scanner variations
  • No permit found → Flag / Hold regardless of animal status
  • Health restriction flag → Flag / Hold regardless of permit
  • Tag not in system → Possible illegal movement → Escalate to supervisor
Tables queried
animals
farmer_premises
farmers
farmer_movement_requests
Query pattern
ilike('tag_serial', val)
parallel: premises + permit
then: farmer name

Module 05 Quarantine Station — Lot Intake & Monitoring Period

11
Lot Intake — 4-Step Wizard
Quarantine supervisor registers the arriving lot at the station
Quarantine SupervisorExport Portal :5003
  • Step 1 — Permit Lookup: Search by movement permit code → system auto-fills origin premises, farmer name, declared animal count
  • Step 2 — Lot Details: Destination country, exporter company, declared species and count, movement purpose (export / domestic slaughter)
  • Step 3 — Pen Assignment: Assign animals to quarantine pens by species; update pen current_count
  • Step 4 — Day-0 Protocols: Record sample collection date (quarantine clock starts here, NOT arrival date), initial health notes, gate-in count
Business rules (WOAH/OIE Chapter 6.5)
  • Quarantine clock starts from sample_collection_date — not arrival date
  • Species separation mandatory — cattle, camels, and small ruminants in separate pens
  • All-in / all-out lot principle — all animals in a lot clear together as one unit
  • Required days: Saudi/UAE/Oman/Kuwait/Bahrain = 21 · Egypt = 28 · Qatar = 30

Step 22 · National LITS Registry
Complete Traceability Record — Farm to Fork
Trace-Back

From any carcass or consignment: → slaughter event → ante-mortem → quarantine lot → movement permit → origin premises → animal birth registration → farmer identity

Trace-Forward

From any registered animal: → all movements → all health events → quarantine lot → slaughter record → carcass code → export consignment → destination market

Disease Response

Identify all animals from same premises, same movement, or same quarantine lot within minutes · Outbreak investigation starts from a single RFID scan · Full history permanently immutable
